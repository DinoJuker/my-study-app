# 🚀 Focus & Task Station (Beta 1.0)

¡Bienvenido a mi proyecto de estación de productividad! Esta es una aplicación móvil desarrollada con **React Native** y **Expo**, diseñada específicamente para ayudar a estudiantes a gestionar sus tareas escolares y mejorar sus periodos de concentración.

## ✨ Características Principales

### ⏳ Temporizador de Enfoque 
- **Rango Flexible**: Ajuste manual desde 10 minutos hasta 5 horas para sesiones de estudio intensas.
- **Pomodoro Integrado**: Botones rápidos para técnica Pomodoro (25m de estudio / 5m de descanso).
- **Fondo Dinámico**: El color de la interfaz cambia suavemente según el progreso del tiempo para reducir la fatiga visual.
- **Frases Motivadoras**: Cada sesión inicia con una frase aleatoria para mantener la disciplina.
- **Reinicio Rápido**: Botón dedicado para resetear el tiempo base en un segundo.

### 📅 Agenda Inteligente con Semáforo
- **Calendario Interactivo**: Visualización mensual para organizar entregas del colegio.
- **Sistema de Prioridades (Semáforo)**:
  - 🔴 **Rojo**: Tareas urgentes o entregas inmediatas.
  - 🟡 **Amarillo**: Tareas importantes con plazo medio.
  - 🔵 **Azul**: Eventos personales o recordatorios generales.
- **Recordatorios Preventivos**: Alerta automática en la pantalla principal sobre las tareas programadas para el día siguiente.
- **Gestión de Tareas**: Capacidad de añadir y eliminar tareas completadas para mantener el orden.

## 🛠️ Tecnologías Usadas
- **React Native**: Framework para la lógica de la aplicación.
- **Expo Go**: Para pruebas y despliegue rápido en dispositivos reales.
- **Lucide React Native**: Iconografía moderna y minimalista.
- **React Native Calendars**: Gestión visual de fechas y eventos.

## 🚀 Instalación y Uso
Para probar esta aplicación en tu dispositivo:

1. Instala la app **Expo Go** desde la Play Store o App Store.
2. Clona este repositorio o abre el código en [Expo Snack](https://snack.expo.dev).
3. Escanea el código QR generado.
4. ¡Empieza a estudiar sin distracciones!
